# test-arena

Работа с этим репозиторием ведётся через [arena.ai](http://arena.ai).

## Продолжение тестирования интеграции с Arena.ai

Интеграция с [Arena.ai](http://arena.ai) продолжает тестироваться. В рамках этого этапа проверяются:

- работа агента в режиме Agent Mode с клоном репозитория;
- создание рабочих веток (`arena/*`), коммиты и отправка изменений на GitHub;
- открытие и слияние pull request в `main`;
- сохранение результатов работы между сессиями.

По мере тестирования в этот раздел будут добавляться новые проверки и их результаты.
